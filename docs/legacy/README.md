# Artist Business Manager

Gestionale personale per attività artistiche e fumettistiche.

Funzionalità previste:

- Gestione progetti
- Commissioni
- Scadenziario
- Clienti
- Fiere ed eventi
- Vendite
- Spese
- Reportistica
- Funzionamento offline tramite PWA
- Salvataggio locale con IndexedDB

## Prerequisiti

Node.js 22.x

Con NVM:

```bash
nvm use 22.22.3
