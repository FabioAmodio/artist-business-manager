# Obiettivo

Sto sviluppando una web app personale per la gestione della mia attività artistica e fumettistica.

L'app NON è un semplice gestionale fiere.

Dovrà gestire:

- Progetti
- Commissioni private
- Lavori editoriali
- Fumetti
- Clienti
- Eventi e fiere
- Vendite
- Prodotti
- Spese
- Pagamenti
- Scadenze
- Reportistica

Requisiti tecnici:

- Angular (ultima versione stabile)
- Standalone Components
- Signals
- PWA
- IndexedDB tramite Dexie
- Nessun backend
- Deploy su GitHub Pages
- Funzionamento offline
- Import/Export completo dei dati

ATTENZIONE:

Per ora NON generare codice applicativo.

Genera esclusivamente la documentazione di progetto:

- docs/architecture/ARCHITECTURE.md
- docs/business/WORKFLOWS.md
- docs/business/TERMINOLOGY.md

L'obiettivo è definire l'architettura tecnica e il dominio prima di implementare qualsiasi funzionalità.
